## 4. Mid-sem ke liye kaise use karo

- Mid-sem (MSE-1) ka syllabus = **Unit 1 + Unit 2**. Har paper ke **Q1–Q3** usually Unit 1-2 se hote hain.
- Pehle `../index.html` ke ★★★★★ questions karo, phir is archive se **same subject ke saare sessions** ke U1-2 questions solve karo (repeat pattern khud dikh jayega).
- Physics/Maths me numericals har saal repeat hote hain — 2022-2026 wale papers me wahi exact numericals milenge.
